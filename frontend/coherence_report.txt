## PROBLÈMES DÉTECTÉS:

###  INCOHÉRENCE CRITIQUE:
- Le frontend envoie 'titre' mais le backend NE LE TRAITE PAS
- Le frontend envoie latitude/longitude mais le backend NE LES TRAITE PAS
- Le frontend envoie adresse/quartier mais le backend NE LES TRAITE PAS
- La base de données a un champ 'titre' OBLIGATOIRE (NOT NULL)
- Le modèle Sequelize NE CONTIENT PAS les champs: titre, latitude, longitude, adresse, quartier

### Solution requise:
1. Mettre à jour le modèle Signalement.js pour inclure TOUS les champs
2. Mettre à jour le controller createSignalement pour traiter TOUS les champs
