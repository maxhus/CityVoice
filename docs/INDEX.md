## 🎓 Glossaire Rapide

| Terme | Signification |
|-------|---------------|
| **Signalement** | Problème urbain signalé par un citoyen |
| **Citoyen** | Utilisateur standard de la plateforme |
| **Administrateur** | Gestionnaire municipal traitant les signalements |
| **Statut** | État d'un signalement (nouveau, en_attente, en_cours, résolu) |
| **Catégorie** | Type de problème (Infrastructure, Propreté, Sécurité, etc.) |
| **Vote** | Action d'un citoyen pour prioriser un signalement |
| **Priorité** | Score calculé basé sur votes, ancienneté, catégorie |
| **Service Municipal** | Département de la ville (Voirie, Éclairage, etc.) |
